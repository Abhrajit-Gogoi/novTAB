# NovTAB here!!

This is NovTAB a "............" new tab for your browser. (it is still in its initial stages so there is not really a good adjective for it.)
I have finished with the v1.0 the basic version that works and has the following features:
- a clock that works and a calendar that shows today's date and day
- a searchbar that works!!!
- a few shortcuts to your favourite sites
- a hover animation

I have used fonts awesome for the icons.
